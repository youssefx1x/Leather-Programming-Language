# Leather (LTH) — Core Specification 0.1

## Identity

Leather is a new programming language inspired by the ideas of Python,
but it is not a Python clone, fork, or reimplementation.

## Core Philosophy

- Semantic Compression
- Intent-First Programming
- Readable Compression
- Minimal Boilerplate
- Progressive Power
- Smart Defaults
- Meaning First, Representation Second
- Intent Completeness
- Performance Transparency
- Explainable Execution
- Full Lower-Level Escape Hatch
